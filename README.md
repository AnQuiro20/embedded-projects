This repository collects embedded-systems projects developed with Arduino, ESP32, and nRF5340 boards. The projects explore sensor integration, local displays, alarms, web interfaces, and connected-device development.

## Project Collection

### Arduino

Located in [`Arduino/`](./Arduino/).

- **Distance radar:** measures distance and presents spatial feedback.
- **OLED temperature station:** reads environmental data and displays it locally.
- **Sound-triggered alarm:** detects sound levels and activates an alert.

### ESP32

Located in [`ESP32/`](./ESP32/).

- **Web-based weather station:** exposes environmental readings through a browser interface.

### nRF5340

Located in [`NRF5340/`](./NRF5340/).

This section contains experiments and projects targeting the Nordic nRF5340 platform.

## Skills Demonstrated

- microcontroller programming
- sensor and peripheral integration
- serial communication and debugging
- embedded web interfaces
- real-time input processing
- hardware-software integration

## Repository Organization

Each platform has its own directory so projects can be documented and extended independently. Future improvements will add a component list, wiring diagram, setup guide, and demonstration media to every project.
